# Men's Beard — Barbershop Website

A modern, responsive landing page for a barbershop, built with React, TypeScript, Vite, and CSS Modules.

## Features

- Modern, premium-inspired UI design
- Responsive layout for desktop and mobile devices
- Services section with pricing
- Barber profiles and team presentation
- Portfolio gallery
- Atmosphere and brand presentation sections
- Instagram integration for customer inquiries
- Reusable React components and modular styling

## Tech Stack

- React
- TypeScript
- Vite
- CSS Modules
- HTML5

## Development

This project was developed with assistance from Claude AI, exploring AI-assisted development workflows, component architecture, responsive styling, and iterative UI refinement.

## Getting Started

```bash
clone <https://github.com/BOgdanRoz/BarberShop-Frontend>
npm install
npm run dev
```

## Build

```bash
npm run build
```
